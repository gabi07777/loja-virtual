
# 🛍️ Minha Loja

Projeto de uma loja virtual desenvolvido com HTML, CSS e JavaScript, com foco em praticar conceitos de desenvolvimento web.

## 📌 Sobre o projeto

O Minha Loja é um projeto desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

A aplicação permite inserir informações do cliente, escolher a forma de pagamento e verificar o valor da compra com a possibilidade de aplicar um desconto.

## 🚀 Funcionalidades

- Cadastro do nome do cliente
- Inserção do valor da compra
- Inserção da idade do cliente
- Seleção da forma de pagamento
- Opção de cupom de desconto
- Cálculo do valor final da compra
- Validação dos campos preenchidos

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Praticar meus conhecimentos em HTML, CSS e JavaScript, desenvolvendo uma aplicação simples e funcional.
